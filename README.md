## How I work

- **Success criteria before code.** Every change starts with a test or check that can fail. A check that cannot go red is not a check.
- **Humans own the risky steps.** Production deploys, database migrations, payments and messages to real people need explicit human approval.
- **Guardrails are code, not reminders.** Rules that can be enforced by a hook or a database policy are enforced there.
- **No invented numbers.** Every figure in this portfolio comes from the system it describes. Where there is no figure, there is none.
